## Case interpretation

Two different accounts own the source and other organizations. Entity requests with the other organization's token cannot access source repositories, waves, budgets, prices, timeline or worker jobs. Collection creates using the other token may succeed in that token's own organization; that is expected. Organization/member endpoints authorize account membership, and public login accepts credentials without a bearer token. A separate empty organization and empty owned repository provide empty list/report cases. GET handlers usually ignore request bodies; the invalid column also sends malformed query values. Body-free actions may legitimately ignore malformed bodies. Ingestion rejects a bearer token without the dedicated machine token. WebSockets use real HTTP Upgrade handshakes.

Local GitLab responses supply project metadata and synthetic issues, with empty merge requests and pipelines. Sync, Work detail and report routes use those persisted records. Worker start/restart invoke only the mounted `worker.sh` fixture, which prints one line and sleeps briefly; stop/read/log and tenant rejection are exercised. Alert channels are disabled and reference unset synthetic variables, so no notification delivery is attempted.

GitHub HMAC authentication was also measured with a locally configured GitHub repository: missing/wrong signature, missing/invalid/empty body each return 400; a valid signature and event return 200 accepted. [Authentication evidence](W18R1-api-501-github-auth.json). This fixture stores no backfill token and uses a local provider base URL.

## Reproduce

Use only a new disposable project/volume and free ports. The full recorded sequence is [commands.md](../../scripts/review-api-501/commands.md); fixtures are committed in `scripts/review-api-501/`. Copy `worker.sh` and `compose.review.yml` to `.agent-runs/W18R1-api-501/` first. Run `provider.py` as an owned process and retain its PID. Set the synthetic environment shown in the command record, start Compose through `scripts/heavy.sh`, bootstrap the three fixture accounts, then run:

```sh

# Enable SCM_REPOSITORIES_JSON for review/synthetic, recreate only this API,
# and wait for /readyz, as shown in commands.md.
```
